# Python Mastery Platform

Learn Python from scratch to advanced level with a focus on AI/ML & Data Science.

## Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS + Framer Motion
- shadcn/ui components
- Pyodide (browser Python runtime)
- Vercel

## Quick Start
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push to GitHub
2. Import repo in [Vercel](https://vercel.com)
3. Framework preset: Next.js
4. Deploy

See `IDEA_PLAN.md` for the full curriculum roadmap and design theme.
